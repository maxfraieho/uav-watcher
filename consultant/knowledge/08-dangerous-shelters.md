# Небезпечні "укриття" — категорично уникати

Ці місця мають хибний вигляд безпеки, але де-факто є зонами підвищеної смертності.

## 1. Ліфтові шахти та кабіни — Пастка знеструмлення

Чому небезпечно:
- Вибух → знеструмлення → заблоковано між поверхами.
- Ліфтова шахта = ідеальна аеродинамічна труба (ефект димоходу). Пожежа на будь-якому поверсі → чадний газ і токсичний дим миттєво затягуються в шахту → асфіксія за хвилини.
- Деформація направляючих рейок від сейсмічного поштовху → обрив кабіни.

**Правило: ліфт під час тривоги — заборонено.**

## 2. Перший поверх з панорамними вікнами

Сучасні комерційні приміщення з суцільним склінням на першому поверсі (магазини, аптеки, банки, ТРЦ).

Чому небезпечно:
- Вся кінетична енергія вибухової хвилі входить через скло прямо в приміщення.
- Фасадне скло без бронеплівки розлітається на великі гострі шматки — шрапнельний ефект.
- Нижні поверхи — максимальна небезпека прямого вогневого контакту.
- Верхні поверхи — максимальна небезпека прямого влучання БПЛА.

**Правило: будь-яке "укриття" з панорамними вікнами — відхиляти.**

## 3. Підвал без другого виходу при загрозі ФАБ/КАБ

Авіабомби ФАБ/КАБ (250–1500 кг): пробивають залізобетонні перекриття кількох поверхів і детонують у фундаменті.

Підвал з єдиним входом під під'їздом = братська могила:
- Завал єдиного виходу → неможливо евакуюватися самостійно.
- Розбір завалу ДСНС важкою технікою — доби.
- Смерть від зневоднення, гіпотермії, нестачі кисню.

**Правило: підвал без другого виходу виправданий тільки як відчайдушний захід під час хаотичного артобстрілу, не при загрозі авіабомб.**

## 4. Застарілі бомбосховища без технічного аудиту

Радянські споруди, що десятиліттями не обслуговувались:
- Порушена гідроізоляція → затоплення ґрунтовими водами.
- Знищені системи фільтровентиляції → накопичення CO₂ при скупченні людей → непритомність.
- Металеві гермодвері не змащені → заклинення від мінімального перекосу рами після вибуху.

**Правило: перевіряй стан сховища заздалегідь, до тривоги. Невідомий стан = ризик.**

## Чек-лист 5 питань для оцінки імпровізованого укриття (10–15 секунд)

1. **Чи є міцне перекриття зверху?**
   - Монолітне або з/б плити ≥300 мм — ТАК.
   - Профнастил, шифер, навіс з полікарбонату, балкон — НІ (пробиваються та утворюють шрапнель).

2. **Чи є несучі стіни з обох боків?**
   - Цегла ≥25 см або монолітний з/б — ТАК.
   - МАФ (кіоск), зупинка, автомобіль, гіпсокартон — НІ (фрагментуються в смертельні уламки).

3. **Чи немає великих вікон поруч?**
   - Глухе приміщення (коридор, тамбур) — ТАК.
   - Вестибюль з вітринними вікнами, скляні двері — НІ (шрапнельний ефект скла).

4. **Чи є другий вихід?**
   - Мінімум 2 розосереджені виходи (для підземних споруд >50 осіб — вимога ДБН В.2.2-5:2023) — ТАК.
   - Підвал з одними дверима — НІ (при обвалі фасаду — заблоковано).

5. **Чи немає транзитних труб?**
   - Без магістральних труб теплоносія/водопостачання — ТАК.
   - Багато труб під стелею → при вибуху розриваються → окріп під тиском у замкненому просторі — НІ.

Кожна негативна відповідь — значне підвищення ризику. Два "НІ" — шукай інше місце.
