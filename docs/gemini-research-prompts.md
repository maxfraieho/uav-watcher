## Промт 1: Типи БПЛА та розпізнавання загроз → `01-uav-types.md`

```
Мені потрібне глибоке дослідження для системи оповіщення цивільних в Україні про загрози з боку БПЛА.

Тема: Розпізнавання типів БПЛА та визначення рівня загрози для цивільного населення

Дослідіть та структуруйте наступне:

1. Класифікація ворожих БПЛА за характеристиками (з яких відстаней чути, як виглядають, на якій висоті летять):
   - Shahed-136/131 (Герань): звук, швидкість, висота польоту, типові маршрути
   - Lancet: характеристики, цілі, ознаки прицілювання
   - Mavic та інші малі комерційні дрони (розвідка vs ударна модифікація)
   - FPV-дрони: відстань виявлення, звукова сигнатура, швидкість

2. Практичні ознаки для цивільних (без спецобладнання):
   - Як розпізнати звук конкретного типу БПЛА
   - Різниця між звуком дрона і звуком звичайного літака/гелікоптера
   - Типова поведінка ударного дрона перед атакою (кола, пікірування)
   - Коли потрібно ховатися негайно vs. коли можна зачекати

3. Дії за типом БПЛА:
   - Shahed летить поруч — алгоритм дій
   - FPV-дрон поблизу — алгоритм дій (менше часу!)
   - Невідомий дрон над об'єктом — алгоритм дій

4. Поширені помилки цивільних при виявленні БПЛА

Формат відповіді: структуровано по секціях з конкретними практичними інструкціями. Джерела: офіційні рекомендації ДСНС, МВС України, ЗСУ, НАТО CIMIC, відкриті дослідження Ukrainian Institute for the Future, CORD.
```

## Промт 2: Система укриттів в Україні → `02-shelters.md`

```
Мені потрібне вичерпне дослідження для бази знань кризового консультанта, який надає поради цивільним під час повітряних тривог в Україні.

Тема: Класифікація укриттів, пошук, підготовка та правила поведінки

Дослідіть наступне:

1. Офіційна класифікація укриттів України (клас А, Б, В, Г):
   - Технічні вимоги до кожного класу
   - Від яких загроз захищає кожен клас
   - Як визначити клас укриття візуально
   - Час перебування, норма повітря на особу

2. Типи укриттів за типом будівлі:
   - Метро: правила входу, правила поведінки, де безпечніше стояти
   - Підземні паркінги: оцінка безпечності, переваги та ризики
   - Підвали житлових будинків: як оцінити міцність, небезпечні ознаки
   - Перший поверх з несучими стінами: коли достатньо, коли ні
   - Внутрішні коридори без вікон: правило двох стін — деталізація

3. Алгоритм вибору укриття за часом до удару:
   - Є 10+ хвилин
   - Є 2-5 хвилин
   - Є менше хвилини (ракета вже летить)
   - Ти в машині на вулиці
   - Ти в полі або відкритій місцевості

4. Підготовка укриття (для тих хто manages об'єкт):
   - Мінімальний набір для укриття
   - Норми запасів на людину
   - Знаки і маркування входу

5. Особливі категорії:
   - Люди з інвалідністю — як знайти доступне укриття
   - З немовлятами — що взяти, де краще розміститися
   - Домашні тварини — правила укриттів
   - Люди, що отримують медичну допомогу

Джерела: накази ДСНС, ДБН В.2.2-5:2022, рекомендації НАТО, практичний досвід Ukrainian Red Cross.
```

## Промт 3: Перша психологічна допомога → `03-psychological-aid.md`

```
Тема: Протоколи психологічної першої допомоги для цивільних під час і після обстрілів

Мета: База знань для AI-консультанта, який відповідає людям в стані паніки, шоку або після травматичного досвіду.

Дослідіть та структуруйте:

1. Гостра стресова реакція — розпізнавання та дії:
   - Фізичні ознаки: тремтіння, оніміння, гіпервентиляція, ступор
   - Вербальні ознаки: "я не можу рухатись", "все скінчено", нечленороздільне
   - Алгоритм першої допомоги для кожного типу реакції
   - Техніки заземлення (5-4-3-2-1 та альтернативи)
   - Техніки дихання (тактичне, квадратне, 4-7-8)

2. Психологічна підтримка дітей:
   - Як пояснити повітряну тривогу дитині 3-5 років
   - Як пояснити дитині 6-12 років
   - Підліткова тривога і заперечення небезпеки
   - Ігри та заняття в укритті для різних вікових груп
   - Ознаки, що дитина потребує фахової допомоги

3. Людина у паніці поруч — що робити:
   - Вербальні техніки заспокоєння
   - Фізичний контакт: коли допомагає, коли шкодить
   - Як направити людину до дії замість паніки

4. Після обстрілу / після укриття:
   - Нормальні реакції в перші 72 години
   - Ознаки ПТСР що розвивається — коли звертатись до фахівця
   - Самодопомога: що рекомендовано, що протипоказано
   - Куди звертатись в Україні (безкоштовні ресурси)

5. Специфіка онлайн-консультування (текстовий чат під час тривоги):
   - Як оцінити рівень дистресу по тексту
   - Ознаки суїцидального ризику в тексті
   - Протокол ескалації

Джерела: WHO Mental Health Gap Action Programme, Ukrainian Crisis Psychology Association, протоколи МОЗ України, ВООЗ, досвід Doctors Without Borders.
```

## Промт 4: Хімічна та радіологічна загроза → `04-chem-radio.md`

```
Тема: Практичні протоколи для цивільних при хімічній або радіологічній загрозі в умовах воєнного часу в Україні

1. Розпізнавання хімічної загрози без спецобладнання:
   - Ознаки хімічної атаки (запах, колір диму, поведінка тварин, симптоми у людей)
   - Типи агентів та їх базові характеристики (нервово-паралітичні, задушливі, шкірно-наривні)
   - Перші симптоми отруєння та їх значення

2. Герметизація приміщення:
   - Покрокова інструкція за 3-5 хвилин
   - Матеріали: що підходить, що ні
   - Пріоритет вентиляційних отворів
   - Скільки часу можна перебувати в герметизованому приміщенні

3. Евакуація при хімічній загрозі:
   - Коли евакуюватись, коли залишатись
   - Напрямок: проти вітру чи перпендикулярно
   - Захист підручними засобами (вологий рушник, одяг)

4. Радіологічна загроза (ядерна станція або брудна бомба):
   - Перші ознаки радіаційної аварії
   - Йодид калію: коли приймати, коли НЕ приймати, дозування по вікових групах
   - "Укритися і залишитись" vs евакуація — критерії рішення
   - Деконтамінація: базові кроки (зняти одяг, душ)
   - Їжа і вода: що безпечно, що ні

5. Аптечка для хімічної/радіологічної загрози:
   - Що повинно бути в домашній аптечці
   - Де взяти йодид калію в Україні
   - Атропін: тільки за рецептом, чому

Джерела: МАГАТЕ, CDC, рекомендації ДСНС, протоколи МОЗ, досвід ВООЗ при Фукусімі та Чорнобилі.
```

## Промт 5: Дії під завалами → `05-rubble-survival.md`

```
Тема: Виживання під завалами та пошуково-рятувальні операції — для цивільних

1. Перші хвилини під завалом:
   - Оцінка ситуації без паніки (алгоритм)
   - Пошук простору під завалом — чому важливо рухатись обережно
   - Захист дихальних шляхів від пилу
   - Самоевакуація: коли можлива, коли небезпечна

2. Сигналізація рятувальникам:
   - Правило "3 удари": стандарт, який знають рятувальники
   - По яких матеріалах стукати (метал, труби — проводять звук найкраще)
   - Чому не можна кричати постійно
   - Мобільний телефон: коли дзвонити, коли тільки SMS

3. Виживання протягом годин:
   - Економія кисню: дихання, рух
   - Температура: як зберегти тепло
   - Вода: де шукати, що не можна пити
   - Психологічна стійкість: техніки збереження фокусу

4. Допомога ззовні (до приїзду ДСНС):
   - Безпечні зони наближення до зруйнованої будівлі
   - Як визначити де може бути живий
   - Що НЕ МОЖНА робити (переміщати важкі елементи)
   - Як координуватись з ДСНС після їх приїзду

5. Оцінка стану врятованого:
   - Crush syndrome (синдром тривалого здавлення): що це, чому небезпечна рання евакуація
   - Перша допомога при краш-синдромі
   - Транспортування при підозрі на травму хребта

Джерела: INSARAG guidelines (ООН), протоколи ДСНС України, FEMA Urban Search and Rescue, Red Cross First Aid protocols.
```
