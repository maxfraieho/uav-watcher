# Соціальна та правова оцінка проекту Sharon

---


> ⚠️ **Дисклеймер:** Цей інструмент є **доповненням** до офіційної системи оповіщення ДСНС, а не її заміною. При сигналі тривоги — негайно прямуйте до найближчого укриття. Дані надходять з публічних Telegram-каналів та AI-аналізу і можуть містити неточності. Рішення про дії завжди залишається за вами.

> AI-компонент може помилятись — як і будь-яка мовна модель (ChatGPT, Gemini, Claude). Розробники не несуть відповідальності за рішення, прийняті на основі порад системи.

## Соціальна оцінка

### Позитивний вплив

**Alert fatigue (психологічне звикання до тривог)**
Підтверджено психологічними дослідженнями: при постійних однотипних попередженнях мозок знижує реакцію. Гіперлокальне оповіщення (рівень конкретного міста, кварталу) зберігає психологічну значущість попереджень і відновлює нормальну реакцію.

**Доступність**
Система працює в Telegram — платформі яку використовують 80%+ українців. Не потрібен окремий застосунок. Не потрібна реєстрація. Підписка на бота — один крок.

**Психологічна підтримка**
Sharon окремо розроблена для кризових психологічних станів:
- Панічні атаки → техніки заземлення
- Ступор → проста інструкція
- Суїцидальний ризик → негайне перенаправлення на 7333 (Lifeline Ukraine)

Це унікальна відмінність від систем оповіщення: не тільки "іди в укриття" але й "ось що робити якщо ти не можеш рухатись".

**Освітній ефект**
База знань Sharon навчає правилам безпеки (правило двох стін, типи загроз, дії при різних сценаріях). Пасивне навчання через реальні запити.

### Ризики та обмеження

**Помилкові негативи (false negatives)**
Якщо система пропустить реальну загрозу — людина яка покладалась на неї може не сховатись.
*Мітигація:* Система є доповненням, не заміною. Обов'язковий дисклеймер. Дворівневий аналіз (keyword + AI + monitor).

**Помилкові позитиви (false positives) → re-alert fatigue**
Занадто часті помилкові алерти дадуть той самий ефект що й оригінальна проблема.
*Мітигація:* Прогресивна система рівнів. Дедуплікація. Інтервали між сповіщеннями. Тестування на реальних даних.

**Технічна залежність**
Відсутність сервера або API → система мовчить. Хибне відчуття захищеності.
*Мітигація:* Моніторинг uptime. Резервний канал (alerts.in.ua). Чіткий дисклеймер.

**Соціальна нерівність**
Люди без Telegram або смартфону не мають доступу.
*Мітигація:* Система не замінює офіційні сирени — лише доповнює для тих хто має доступ.

## Правова оцінка

### Що регулює

| Аспект | Регулювання |
|--------|-------------|
| Збір публічних даних | Telegram ToS (публічні канали — публічна інформація) |
| Персональні дані | Закон України "Про захист персональних даних" |
| Діяльність бота | Правила Telegram Bot API |
| Система оповіщення | Закон України "Про правовий режим воєнного стану" |
| Відповідальність за інформацію | ЦК України, ст. 1166–1167 |

### Публічні Telegram-канали

Повідомлення в публічних каналах є публічною інформацією. Їх читання, агрегування та аналіз не є порушенням законодавства про персональні дані — канали свідомо публікують інформацію для необмеженої аудиторії.

**Статус:** ✅ Правомірно

### Telegram userbot (Telethon)

Технічно Telegram забороняє автоматизацію особистих акаунтів через ToS. Однак:
- Моральний контекст воєнного стану
- Широка поширеність такого використання в Україні для моніторингу
- Відсутність комерційної складової
- Читання тільки публічних каналів (не особистого листування)

**Ризик:** Telegram може заблокувати акаунт. Практика показує толерантність до некомерційних моніторингових ботів.
**Мітигація:** Окремий акаунт для userbot. Помірна частота запитів.

### Персональні дані

Система **не збирає** персональні дані:
- Telegram ID користувачів не зберігається (крім `notify_chat_id` в config — власний вибір власника)
- Повідомлення з каналів — публічна інформація без прив'язки до осіб
- `/correct` зберігає тільки текст виправлення без авторства

**Статус:** ✅ Відповідає вимогам ЗУ "Про захист персональних даних"

### Відповідальність за інформацію

Система надає **агреговану** інформацію з публічних каналів + AI-аналіз. Вона є інформаційним інструментом, не офіційним органом оповіщення.

**Необхідні дисклеймери:**
```
⚠️ Це не офіційна система оповіщення. Дані надаються з публічних Telegram-каналів
та AI-аналізу. Завжди слідуйте офіційним інструкціям ДСНС та місцевої влади.
Рішення про дії ви приймаєте самостійно.
```

**Статус:** ✅ При наявності дисклеймеру відповідальність обмежена

### Система оповіщення та воєнний стан

Система не претендує на роль офіційного оповіщення і не підміняє державні системи. Вона є цивільним інструментом самодопомоги.

**Статус:** ✅ Не суперечить законодавству про воєнний стан

## Рекомендації для легального розгортання

1. **Додати дисклеймер** у кожне сповіщення (скорочений варіант)
2. **Окремий акаунт** для Telegram userbot
3. **Публічна документація** про те які канали читаються
4. **Не видавати** себе за офіційну структуру (ДСНС, ЗСУ, ОВА)
5. **Механізм виключення** — можливість відписатись від сповіщень
6. **Відкритий код** — прозорість алгоритмів підвищує довіру

## Висновок

Проект Sharon:
- **Соціально:** Корисний, адресує реальну проблему alert fatigue, додає психологічну підтримку
- **Правово:** При наявності дисклеймерів та без претензій на офіційний статус — правомірний
- **Ризики:** Технічно та інформаційно керовані при правильному впровадженні

Система є цивільним інструментом взаємодопомоги в умовах воєнного стану — етично виправдана та суспільно корисна.
