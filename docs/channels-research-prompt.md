# Промт для пошуку Telegram-каналів моніторингу БПЛА

Скопіюйте цей промт у Google або ChatGPT для пошуку актуальних каналів.

---

## Промт для ChatGPT / Google Gemini

```
Я розробляю систему моніторингу БПЛА-загроз для міста Олександрія (Кіровоградська область, Україна).
Система слідкує за Telegram-каналами і класифікує повідомлення через AI.

Допоможи знайти Telegram-канали, які:
1. Публікують повідомлення про повітряні тривоги в Кіровоградській області або в Олександрії зокрема
2. Публікують дані про БПЛА (дрони) та ракетні загрози в Центральній Україні
3. Є оперативними — повідомляють до або під час тривоги, а не після

Потрібні:
- Назва каналу в Telegram (@username або t.me/...)
- Тематика (регіональний, загальнонаціональний, офіційний ВА тощо)
- Частота публікацій (якщо відомо)

Відомі мені канали (не повторюй):
- УНІАН (загальнонаціональний)

Додатково — де краще шукати такі канали вручну в Telegram?
```

## Пошукові запити для Google

```
site:t.me "повітряна тривога" "Кіровоградська"
site:t.me "БПЛА" "Олександрія" OR "Кіровоградська"
telegram канал повітряна тривога Кіровоградська область
telegram "антидрон" OR "ПВО" Кіровоградщина
"Кіровоградська область" БПЛА моніторинг telegram
```

---

## Де шукати вручну в Telegram

1. **Пошук у Telegram**: ввести `повітряна тривога кіровоград`, `БПЛА олександрія`, `антидрон кіровоградська`
2. **tgstat.ru / tgstat.com.ua**: пошук по ключових словах в описах каналів
3. **Telemetr.me**: каталог українських Telegram-каналів, фільтр по темі "Безпека"
4. **Офіційні джерела**:
   - Кіровоградська ОВА (обласна військова адміністрація) — офіційний канал
   - Управління ДСНС в Кіровоградській області
   - Олександрійська міська рада — може дублювати тривоги
5. **Перехресні посилання**: відкрити відомий канал → подивитись які канали він рекомендує або пересилає

## Як додати новий канал до моніторингу

1. Знайти числовий ID каналу:
   - Переслати будь-яке повідомлення з каналу боту [@userinfobot](https://t.me/userinfobot)
   - Або [@getmyid_bot](https://t.me/getmyid_bot)
   - ID буде від'ємним числом, наприклад `-1002187970584`

2. Додати в `config.json`:
```json
"channels": [-1002187970584, -1001234567890]
```

3. Перезапустити сервіс:
```bash
sudo rc-service uav-watcher restart
```

## Критерії відбору каналу

✅ Підходить:
- Публікує тривоги для Кіровоградської області або Центральної України
- Оперативний (публікації під час тривоги, а не через годину)
- Конкретні дані: напрямок, тип загрози, підтвердження

❌ Не підходить:
- Тільки загальнонаціональні зведення без регіональної деталізації
- Новинні канали (публікують після події)
- Канали з низькою активністю (менше 3-5 публікацій на день під час загострень)
