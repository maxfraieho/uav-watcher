## 1. Що таке UAV Watcher

**UAV Watcher** — це програма, яка моніторить Telegram-канали з повітряними тривогами і надсилає сповіщення вам і вашій родині.

### Можливості

| Функція | Опис |
|---------|------|
| 📡 Моніторинг каналів | Слідкує за кількома Telegram-каналами одночасно |
| 🤖 AI-аналіз | Класифікує тип загрози (балістика, дрони, артилерія) |
| 💬 Сповіщення | Надсилає короткі сповіщення у ваш Telegram |
| 🌐 Веб-інтерфейс | Налаштування через браузер, без командного рядка |
| 🔗 Публічне посилання | Родина бачить статус тривоги і може знайти укриття |
| 🏠 Пошук укриттів | AI знаходить найближчі укриття за геолокацією |
| 🆘 Сигнал рятувальника | Автоматичний SOS при ударі та нерухомості |
| 🛰️ P2P мережа | Сусідні станції автоматично отримують ваш SOS |

### Де запускати

- **Android** — у застосунку Termux (телефон або планшет)
- **Linux** — будь-який сервер або Raspberry Pi
- **Завжди увімкнено** — краще залишати працювати 24/7

## 2. Встановлення

### Автоматичне встановлення (рекомендовано)

**Крок 1.** Відкрийте Termux або термінал Linux.

**Крок 2.** Скопіюйте та запустіть команду:

```bash
curl -s https://raw.githubusercontent.com/maxfraieho/uav-watcher/master/install.sh | bash
```

**Крок 3.** Дочекайтеся завершення — займає 1–3 хвилини.

Інсталятор:
- встановить Python та необхідні бібліотеки
- створить теку `~/uav-watcher/`
- налаштує автозапуск (Termux, systemd або cron)

### Що встановлюється

```
~/uav-watcher/
├── uav_watcher.py    — головна програма
├── web_config.py     — веб-інтерфейс налаштувань
├── config.json       — налаштування (редагувати через браузер)
├── .env              — секретні ключі (API token)
└── start.sh          — скрипт запуску
```

## 3. Перший запуск і налаштування

### Запуск

```bash
cd ~/uav-watcher
bash start.sh
```

Або у Termux просто відкрийте застосунок — якщо встановлено автозапуск, програма запускається сама.

### Відкрийте веб-інтерфейс

На тому ж пристрої, де запущено програму, відкрийте браузер:

```
http://localhost:8422
```

Якщо налаштовуєте з іншого пристрою в тій же мережі — замініть `localhost` на IP-адресу пристрою (наприклад, `http://192.168.1.100:8422`).

### Обов'язкові налаштування

#### 1. API Token Telegram

Потрібен для авторизації у Telegram:

1. Напишіть [@BotFather](https://t.me/BotFather) у Telegram
2. Введіть `/newbot` і дайте назву боту
3. Скопіюйте токен (формат: `1234567890:AAEfzH9...`)
4. Вставте у веб-інтерфейсі у розділ **Bot** → поле **Bot Token**

> ⚠️ Токен зберігається у файлі `.env` і ніколи не передається стороннім.

#### 2. Ваш Telegram Chat ID

Щоб бот надсилав сповіщення саме вам:

1. Напишіть [@userinfobot](https://t.me/userinfobot) у Telegram
2. Відправте будь-яке повідомлення — бот відповість з вашим ID
3. Скопіюйте число і вставте у **Notify Chat ID**

#### 3. Місто

У розділі **Місто** вкажіть назву вашого міста або села (наприклад: `Олександрія`, `Харків`, `Бровари`). Це допомагає AI фільтрувати повідомлення, що стосуються саме вашого регіону.

#### 4. Канали моніторингу

Один канал — [Повітряні Сили ЗС України](https://t.me/kpszsu) — підключений автоматично. Додайте інші канали:

- Введіть `@username` каналу або його числовий ID
- Натисніть **Додати**

Рекомендовані канали:
- `@air_alert_ua` — Повітряна тривога Україна
- `@Ukraine_alarm` — СТОП Корупції (тривоги)
- Регіональні канали вашої області

## 5. Публічна сторінка для родини

Коли ви налаштуєте Cloudflare Tunnel (розділ 9), ви отримаєте публічне посилання вигляду:

```
https://вашпрефікс-alert.exodus.pp.ua/share
```

Це посилання можна:
- **Поділитися з родичами** — вони відкривають і бачать статус
- **Показати QR-код** — зручно для людей похилого віку (сканують телефоном)

### Що бачить родина на сторінці /share

#### 📊 Статус моніторингу
Показує, що система активна і скільки каналів відслідковується.

#### 📨 Підключити Telegram бот
Кнопка, яка відкриває бота у Telegram. Родич натискає `/start` — і бот запам'ятовує його для отримання сповіщень.

#### 🏠 Найближчі укриття
Натиснути кнопку **Визначити місцезнаходження** — браузер запитає дозвіл на геолокацію. Після підтвердження система:
1. Визначить поточні координати
2. Запитає базу укриттів (OpenStreetMap)
3. Покаже найближчі укриття з відстанню і кнопкою "Показати на карті"

> Якщо в базі немає укриттів для вашого міста — це нормально для невеликих населених пунктів. Скористайтесь AI-консультантом.

#### 🤖 AI-консультант
Чат, де можна запитати поради щодо безпеки. Приклади питань:
- *"Оголошено балістичну загрозу, що робити?"*
- *"Де знайти найближче укриття в підвалі?"*
- *"Як поводитись під час дрону-камікадзе?"*

## 7. Режим рятувальника

> Для людей, які входять у небезпечну зону — пошкоджену будівлю, підвал, зону обстрілу.

### Що це робить

Якщо телефон виявить **удар** (різке прискорення) і потім тривалу **нерухомість** (30 секунд), він автоматично:

1. 🔊 Відтворить гучний SOS-сигнал (азбука Морзе: ⋅⋅⋅ ─ ─ ─ ⋅⋅⋅)
2. 📍 Визначить ваші координати
3. 📨 Надішле SOS-повідомлення у ваш Telegram з посиланням на карту
4. 📡 Сповістить сусідні станції UAV Watcher (якщо налаштовані)

### Як активувати

1. Відкрийте публічну сторінку: `https://вашпрефікс-alert.exodus.pp.ua/share`
2. Прокрутіть до картки **⚠️ Сигнал рятувальника**
3. Натисніть **🛡️ Увімкнути захист**
4. Браузер запитає дозвіл на геолокацію — підтвердіть

### Стани

| Стан | Опис |
|------|------|
| ⚫ Вимкнено | Захист не активний |
| 🔴 Активний | Моніторить рух. Зелений індикатор пульсує |
| ⚠️ Зворотній відлік | Виявлено удар + нерухомість. Рахує 30 с до SOS |
| 🚨 SOS | Повноекранне попередження, сирена, надіслано сповіщення |

### Ручний SOS

Якщо потрібно надіслати сигнал негайно (датчик не спрацював) — у режимі **Активний** натисніть **🆘 НАДІСЛАТИ SOS ЗАРАЗ**.

### Обмеження

- Потребує відкритого браузера на телефоні (сторінка активна)
- iOS потребує підтвердження дозволу на датчик руху
- Якщо телефон заблоковано — датчик не працює (лишіть екран увімкненим)

## 8. P2P мережа рятування між сусідами

### Навіщо

Якщо людина під завалом, а рятувальники не знають де вона — ніхто не може їй зателефонувати. **P2P мережа** дозволяє сусіднім станціям UAV Watcher автоматично отримати SOS-сигнал і повідомити своїх операторів.

### Як це працює

```
Людина А (під завалом)          Сусід Б (за 2 км)
    📱 SOS спрацьовує    ──────>  📡 Станція Б отримує SOS
    📨 Надсилається         📲 Telegram-повідомлення сусіду Б
       в Telegram А    
                             Сусід В (за 5 км)
                         ──> 📡 Станція В отримує SOS
                             📲 Telegram-повідомлення сусіду В
```

Кожен сусід, хто отримав сповіщення, може зреагувати і викликати рятувальників.

### Налаштування

**Крок 1.** Домовтесь із сусідами, у яких теж є UAV Watcher.

**Крок 2.** Обміняйтесь публічними посиланнями ваших тунелів (наприклад: `https://іванко-alert.exodus.pp.ua`).

**Крок 3.** Додайте посилання сусідів у `config.json`:

```json
"rescue_peers": [
  "https://іванко-alert.exodus.pp.ua",
  "https://maria22-alert.exodus.pp.ua"
]
```

> Файл `config.json` знаходиться у теці `~/uav-watcher/`. Відредагуйте будь-яким текстовим редактором.

**Крок 4.** Перезапустіть сервіс:
```bash
cd ~/uav-watcher && bash start.sh
```

### Перевірка

Відправте тестовий SOS через сторінку `/share` — у Telegram кожного сусіда має з'явитися повідомлення з позначкою **SOS-ретрансляція**.

## 9. Cloudflare Tunnel — публічне посилання

Tunnel дозволяє родині у будь-якій точці світу відкрити вашу сторінку без налаштування роутера або відкритих портів.

### Вимоги

- Встановлений `cloudflared` (інсталятор робить це автоматично)
- Файли доступу у теці `~/uav-watcher/.cloudflared/` (додаються при встановленні)

### Налаштування Tunnel

1. Відкрийте веб-інтерфейс: `http://localhost:8422`
2. Знайдіть картку **Tunnel**
3. У полі **Префікс** введіть бажаний піддомен (лише латиниця і цифри, 2–20 символів)
   - Приклад: `miy-dim`, `ivanka2024`, `rodyna`
4. Натисніть **Перевірити** — система перевірить, що префікс вільний
5. Натисніть **Запустити Tunnel**

Ваше посилання буде:
```
https://rodyna-alert.exodus.pp.ua
```

Сторінка для родини:
```
https://rodyna-alert.exodus.pp.ua/share
```

### QR-код

Після запуску Tunnel — під посиланням з'явиться QR-код. Родина сканує його телефоном — і одразу потрапляє на вашу сторінку.

### Зупинити Tunnel

Натисніть **Зупинити** у картці Tunnel. Посилання перестане працювати.

> Tunnel автоматично зупиняється при перезапуску програми. Запускайте його щоразу вручну або налаштуйте автозапуск через `start.sh`.

## 10. Автозапуск

### Termux (Android)

Якщо встановлений **Termux:Boot** з F-Droid:

1. Програма запускається автоматично при перезапуску телефону
2. Нічого додатково налаштовувати не потрібно

Перевірити:
```bash
ls ~/.termux/boot/
# Має бути файл uav-watcher.sh
```

Якщо файл відсутній:
```bash
mkdir -p ~/.termux/boot
cp ~/uav-watcher/start.sh ~/.termux/boot/uav-watcher.sh
chmod +x ~/.termux/boot/uav-watcher.sh
```

### Linux (systemd)

Перевірити статус:
```bash
systemctl --user status uav-watcher.service
systemctl --user status uav-web-config.service
```

Запустити вручну:
```bash
systemctl --user start uav-watcher.service
systemctl --user start uav-web-config.service
```

Вимкнути автозапуск:
```bash
systemctl --user disable uav-watcher.service
```

### Ручний запуск

```bash
cd ~/uav-watcher
bash start.sh
```

Щоб зупинити: натисніть `Ctrl+C` або закрийте термінал.

## 11. Часті запитання

**❓ Бот не надсилає сповіщення**

Перевірте:
1. Веб-інтерфейс → Bot Token та Notify Chat ID заповнені
2. Ви написали `/start` боту у Telegram
3. Бот не заблокований у вашому Telegram (перейдіть до бота та перевірте)

---

**❓ Програма не запускається після перезавантаження Termux**

1. Переконайтеся, що Termux:Boot встановлено з **F-Droid** (не Google Play)
2. Відкрийте Termux:Boot і переконайтесь, що він активований у системних налаштуваннях (автозапуск застосунків)
3. Запустіть вручну: `cd ~/uav-watcher && bash start.sh`

---

**❓ Веб-інтерфейс не відкривається**

```bash
pgrep -af web_config.py
```

Якщо процес не знайдено:
```bash
cd ~/uav-watcher && python3 web_config.py &
```

---

**❓ Tunnel не запускається**

1. Переконайтеся, що файли у `~/.cloudflared/` або `~/uav-watcher/.cloudflared/` існують
2. Перевірте інтернет-з'єднання
3. Спробуйте інший префікс (поточний може вже використовуватися)

---

**❓ Укриттів не знайдено**

Це нормально для невеликих міст — база OpenStreetMap містить лише публічно нанесені об'єкти. Що робити:
- Запитайте у AI-консультанті загальні рекомендації
- Зверніться до місцевої влади або волонтерів для отримання актуального списку укриттів
- Підвальні приміщення житлових будинків — теж укриття

---

**❓ Датчик руху не спрацьовує (iOS)**

Safari на iOS потребує явного дозволу на DeviceMotion. При натисканні **Увімкнути захист** з'явиться системний запит — підтвердіть. Якщо запит не з'являється:
1. iOS → Налаштування → Safari → Доступ до рухів і орієнтації → Дозволити

---

cd ~/uav-watcher
