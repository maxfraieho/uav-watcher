# Sharon

> Гіперлокальна AI-система моніторингу повітряних загроз і кризової підтримки.

> 🚧 **Статус: активна розробка.** Функціонал може бути нестабільним. Частина можливостей ще реалізовується. Використовуйте з розумінням обмежень.

---

> ⚠️ **Відмова від відповідальності (AI Disclaimer)**
>
> Система використовує штучний інтелект (LLM) для аналізу та надання порад. Як і будь-яка AI-система (ChatGPT, Gemini, Claude та інші) — **вона може помилятись**. Розробники не несуть відповідальності за рішення, прийняті на основі інформації від AI-компонента.
>
> Система є **доповненням** до офіційної системи оповіщення ДСНС, а не її заміною. При сигналі тривоги — негайно прямуйте до укриття. Рішення завжди залишається за вами.

---

## Проблема

Загальноукраїнська тривога лунає **40–60 разів на місяць**. Більшість з них охоплює половину країни, хоча реальна загроза локалізована в одному районі.

Результат — **alert fatigue**: психологічне звикання. Мозок перестає сприймати кожне попередження як реальну небезпеку. Люди залишаються вдома не тому, що вони безвідповідальні — а тому, що сигнал **загубився в шумі**.

**Рішення не в тому, щоб кричати голосніше. А в тому, щоб говорити точніше.**

## Що робить система

Sharon відстежує 5+ Telegram-каналів у реальному часі, класифікує повідомлення за допомогою AI і надсилає **прицільне сповіщення** лише тоді, коли загроза наближається до вашого міста.

**Для жителя:**
- Сповіщення приходить коли це справді важливо для вашого міста — не для Харкова чи Одеси
- Рівень сповіщення відображає реальну небезпеку: БПЛА в регіоні ≠ БПЛА над містом
- Sharon відповідає на "Як обстановка?" реальними даними, а не шаблонними фразами

**Для психологічної безпеки:**
- При паніці — техніки заземлення
- При ступорі — прості конкретні інструкції
- При суїцидальному ризику — гаряча лінія 7333 (Lifeline Ukraine)

## Рівні сповіщень

```
Рівень 0 — Тиша           Загроз у регіоні немає. Без повідомлень.

Рівень 1 — ⚠️ СПОСТЕРЕЖЕННЯ   БПЛА/ракети виявлені в регіоні, рух невизначений.
                               Повторення: не частіше 1 разу на 30 хв.

Рівень 2 — 🚨 ТРИВОГА 🚨       Тривога оголошена по місту / рух у напрямку міста.
                               Повторення: не частіше 1 разу на 10 хв.

Рівень 3 — 🔴🔴🔴 НЕБЕЗПЕКА!    БПЛА або ракети безпосередньо над містом, вибухи.
                               Повторення: не частіше 1 разу на 5 хв.
```

**Ескалація** (1→2, 2→3): сповіщення миттєво, без очікування інтервалу.

## Sharon — AI-помічник з безпеки

Sharon — це не чат-бот для розваг. Це кризовий AI-інструмент, розроблений спеціально для умов воєнного стану. Кожне місто розгортає **власний** екземпляр з локальною базою знань — Sharon не знає вашого міста поки ви її не навчите.

### Як Sharon отримує інформацію

Sharon не відповідає з шаблонних фраз — вона збирає контекст із кількох джерел одночасно:

```
Ваш запит
    ↓
retrieve_kb()
    ├─ channel_feed     → останні повідомлення каналів (real-time, до 2 год)
    ├─ summarizer       → AI-зведення за останню годину (кожні 5 хв)
    ├─ situation        → alerts.in.ua — статус тривог по областях (кожні 60 с)
    ├─ BM25Plus KB      → база знань: укриття, дії при загрозах, медична допомога
    └─ web_search       → DuckDuckGo (лише при запитах про конкретне місце/подію)
    ↓
generate() — Llama 4 Maverick → відповідь з контекстом
```

**Результат:** "Як обстановка?" — Sharon дає реальне зведення за останню годину, а не шаблонне "у вашому регіоні зафіксовано активність".

### Сценарії та відповіді

| Ситуація | Що відбувається | Відповідь |
|----------|----------------|-----------|
| "Як обстановка?" | Читає channel_feed + AI-зведення | Тактичний звіт: що, де, коли |
| "Чую БПЛА!" | Crisis mode → KB: укриття | Правило двох стін, конкретні дії |
| "Де найближче укриття?" | KB: shelter.md вашого міста | Адреси, маршрути |
| "Що робити при вибуху?" | KB: дії при вибуху | Покрокова інструкція |
| Паніка (CAPS, !!!) | detect_crisis_state() → PANIC | Техніки 5-4-3-2-1, дихання |
| Ступор (`. . .`, мовчання) | detect_crisis_state() → STUPOR | Одне питання: "Де ти зараз?" |
| Суїцидальні думки | Crisis escalation | Гаряча лінія 7333, без суджень |
| Офтопік / загальні питання | Повертає до теми безпеки | — |
| `/correct <текст>` | Записує виправлення до KB | База знань оновлюється |

### Пам'ять та сесії

Sharon пам'ятає контекст розмови через `MemorySaver` (LangGraph). Кожна вкладка браузера — окрема сесія (UUID у `localStorage`). Сервер нічого не зберігає між сесіями — перезавантаження сторінки починає нову розмову.

### Самонавчання через `/correct`

Будь-який користувач може виправити Sharon прямо в чаті:

```
/correct Укриття в школі №5 — зачинено. Відкритий підвал будинку на вул. Миру 12
```

Виправлення зберігаються в `consultant/knowledge/corrections.md`. Watchdog відстежує зміни файлів і автоматично переіндексовує — без перезапуску сервісу.

### Знання про ваше місто (knowledge base)

Sharon читає `.md` файли з `consultant/knowledge/`. Для нового міста обов'язково додати:

| Файл | Зміст |
|------|-------|
| `shelter.md` | Адреси укриттів, режим роботи |
| `local.md` | Особливості міста: підземні переходи, підвали, небезпечні зони |
| `routes.md` | Безпечні маршрути до укриттів |

Файли можна редагувати під час роботи — Sharon переіндексує їх автоматично.

## Архітектура

```
Telegram-канали (5+)
    ↓ Telethon userbot
    ├─► keyword_classify() — миттєво, без AI
    ├─► ai_classify()      — Llama 4 Maverick, складні випадки
    ├─► send_notification() — підтверджена загроза → Telegram бот
    └─► channel_feed.db    — SQLite ring buffer (500 повідомлень, 2 год)
              ↓
    situation_monitor (daemon)
         ├─ кожні 5 хв якщо є загрози
         ├─ кожні 30 хв коли тихо
         └─ LLM → рівень 0–3 → прогресивне сповіщення

Sharon / consultant/ — FastAPI :8770
    retrieve_kb()
         ├─ channel_feed   → сировий feed (real-time)
         ├─ summarizer     → AI-зведення кожні 5 хв
         ├─ situation      → alerts.in.ua (кожні 60 с)
         └─ BM25Plus       → knowledge base (.md, auto-reindex)
    web_search()           → DuckDuckGo (time-sensitive запити)
    generate()             → Llama 4 Maverick → відповідь
    MemorySaver            → session history per browser tab
```

## Розгортання

### Мінімальні вимоги

- Python 3.11+
- 512 MB RAM (Raspberry Pi 4 — достатньо)
- Telegram акаунт (для userbot)
- Telegram Bot Token (через @BotFather)
- [NVIDIA NIM API key](https://build.nvidia.com/) — безкоштовний tier: 1000 запитів/день

### Кроки

```bash
# 1. Клонувати
git clone https://github.com/YOUR_ORG/uav-watcher
cd uav-watcher

# 2. Залежності
pip install -r requirements.txt

# 3. Конфіг
cp config.example.json config.json
# Заповніть: city, city_lat, city_lon, channels, bot_token, notify_chat_id, llm_proxy_*

# 4. Telethon авторизація (одноразово)
export TELEGRAM_PHONE="+380XXXXXXXXX"
python -c "from telethon.sync import TelegramClient; c = TelegramClient('bot', API_ID, API_HASH); c.start()"

# 5. Запуск
python uav_watcher.py &         # userbot + бот + монітор
python consultant/main.py &     # Sharon API :8770
```

## Правова позиція

Повна оцінка: [legal-social-assessment.md](legal-social-assessment.md)

**Ключове:**
- Моніторуються лише **публічні** Telegram-канали (публічна інформація)
- Персональні дані **не збираються** і **не зберігаються**
- Система є **доповненням** до ДСНС, не замінює і не дублює офіційне оповіщення
- Рішення про дії користувач приймає самостійно

```
⚠️ Не є офіційною системою оповіщення. Дані надходять з публічних
Telegram-каналів та AI-аналізу. Завжди слідуйте офіційним інструкціям
ДСНС та місцевої влади. Ідіть до укриття при сигналі тривоги.
```
